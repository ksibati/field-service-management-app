# 🛠️ Field Service Management App

A cross-platform mobile application built with **Flutter** designed for managing field service workshops, tracking daily operations, tasks, and client requests for construction, painting, and maintenance contractors.

## ✨ Features

- **Workshop & Site Management:** Efficiently manage daily operations across various sites (construction, painting, workshops).
- **Task & Progress Tracking:** Monitor ongoing tasks, assignments, and work statuses in real time.
- **Cross-Platform:** Built using Flutter to support both Android and iOS seamlessly.
- **Modern UI/UX:** Clean and intuitive user interface designed for workers and project managers.

---

## 🚀 Tech Stack

- **Framework:** [Flutter](https://flutter.dev)
- **Language:** [Dart](https://dart.dev)
